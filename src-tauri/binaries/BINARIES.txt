

Tauri Whisper sidecar bundle
===========================

Naming
------
  whisper-cli-<RUST_HOST_TRIPLE>[.exe]     (`rustc --print host-tuple`)

Setup (Windows host)
--------------------
  npm run setup:whisper          # downloads OpenBLAS CPU CLI + quantized base.en (q8_0)

  npm run setup:whisper -- --gpu # optional: NVIDIA CUDA 12.4 cuBLAS binaries (requires CUDA runtime)

Windows also requires the **DLL bundle** from that zip (copied by the script into):
  `src-tauri/resources/whisper_runtime/` — `ggml.dll`, `libopenblas.dll`, etc. The app prepends this
  directory to `PATH` at startup so whisper-cli loads correctly in dev and in the installed bundle.

Setup (macOS host)
------------------
  `npm run setup:whisper` downloads whisper.cpp **v1.8.4** sources and CMake-builds
  **`whisper-cli-<triple>`** (`BUILD_SHARED_LIBS=OFF`).
  Requires **Apple Command Line Tools** (`xcode-select --install`; full Xcode optional), CMake, `tar`, and `rustc`.

  Typical triples: `aarch64-apple-darwin`, `x86_64-apple-darwin`.

  Optional **`resources/whisper_runtime/*.dylib`**: Rust prepends that directory to **`DYLD_LIBRARY_PATH`**
  on startup when `.dylibs` are present (shared whisper builds).

Linux / other hosts
--------------------
  npm run setup:whisper downloads the quantized model only. Build whisper.cpp and copy the sidecar into
  **`binaries/`** matching **`rustc --print host-tuple`**.

Bundled assets are git-ignored (*.exe, *.bin, CMake build dirs under `binaries/` on macOS) — run setup after clone.
