## What's new

**Mello Voice 1.0.11** focuses on faster, more reliable startup — especially if the app seemed to “open and close” or needed several tries before it worked.

- **Lighter launch** — Mello no longer spins up the floating dictation bar until you need it, so opening the app uses less memory and feels snappier on first run.
- **Clearer loading** — the Loading screen appears right away while local transcription warms up, instead of a blank window.
- **Smarter relaunch** — if Mello is already running in the tray and you open it again from the desktop or Start menu, the existing window comes back instead of flashing and disappearing.

## Install

### Windows

Use the **Direct downloads** links above — **Windows setup (.exe)** is recommended; **MSI** is included for managed installs.

- **Windows 10 or 11 (64-bit)** and **Microsoft Edge WebView2** (usually already installed).
- Allow **microphone** access when Mello Voice asks. If access wasn’t granted, tap **Allow microphone access** in the app to try again.
- This build is **not code-signed** yet — SmartScreen may say “Unknown publisher”. Choose **More info → Run anyway** if you trust this download.

Installers include the Whisper runtime and English model — no extra download after install.
