## What's new

**Mello Voice 1.0.8** improves the dictation bar and makes local transcription more reliable.

- **Live audio meter** — while you speak, the floating bar shows a scrolling waveform so you can see the mic is picking you up.
- **Double-tap to stop** — the bar reminds you how to finish dictation with your chosen shortcut key.
- **More reliable quiet speech** — softer voice and pauses are less likely to be trimmed away before transcription.
- **Keeps listening when you switch focus** — dragging the main window or clicking elsewhere no longer drops an active dictation session.
- **Smoother bar animation** — the listening pill opens and closes without the label jumping or reflowing mid-transition.
- **Whisper-only transcription** — finished text always comes from local Whisper on your computer; the overlay no longer mixes in browser speech preview.

## Install

### Windows

Use the **Direct downloads** links above — **Windows setup (.exe)** is recommended; **MSI** is included for managed installs.

- **Windows 10 or 11 (64-bit)** and **Microsoft Edge WebView2** (usually already installed).
- Allow **microphone** access when Mello Voice asks. If access wasn’t granted, tap **Allow microphone access** in the app to try again.
- This build is **not code-signed** yet — SmartScreen may say “Unknown publisher”. Choose **More info → Run anyway** if you trust this download.

Installers include the Whisper runtime and English model — no extra download after install.
