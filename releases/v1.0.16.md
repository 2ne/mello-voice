## What's new

**Mello Voice 1.0.16** is open source — and long dictation sessions now stop cleanly on their own.

- **Open source (MIT)** — the full app is on [GitHub](https://github.com/2ne/mello-voice). Inspect the code, report issues, or contribute if you like.
- **10-minute session limit** — if you dictate for ten minutes straight, Mello stops listening, transcribes what you said, and pastes it into the focused field (using your **Paste text** or **Paste and send** setting).
- **Updated landing page** — download links, FAQ, and support info live at [2ne.github.io/mello-voice](https://2ne.github.io/mello-voice/).

## Install

### Windows

Use the **Direct downloads** links above — **Windows setup (.exe)** is recommended; **MSI** is included for managed installs.

- **Windows 10 or 11 (64-bit)** and **Microsoft Edge WebView2** (usually already installed).
- Allow **microphone** access when Mello Voice asks. If access wasn’t granted, tap **Allow microphone access** in the app to try again.
- This build is **not code-signed** yet — SmartScreen may say “Unknown publisher”. Choose **More info → Run anyway** if you trust this download.

Installers include the Whisper runtime and English model — no extra download after install.
