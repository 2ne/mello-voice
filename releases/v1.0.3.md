## What's new

**Mello Voice 1.0.3** improves microphone onboarding when access wasn’t granted — especially on Windows.

- Clearer messaging when the microphone wasn’t allowed — no jargon about “Block,” just what to do next.
- **Windows:** **Show permission prompt again** resets the in-app choice (Mello Voice often doesn’t appear in the Windows Settings app list). **Open Windows microphone settings** is there if you still need system toggles.
- **macOS:** Open microphone settings, enable Mello Voice, then **Check again**.
- Less cluttered blocked screen — the extra microphone icon and duplicate line of text are hidden when recovery is shown.
- Slightly more space under the **Mello Voice** title on the welcome screen.

## Install

### Windows

Use the **Direct downloads** links above — **Windows setup (.exe)** is recommended; **MSI** is included for managed installs.

- **Windows 10 or 11 (64-bit)** and **Microsoft Edge WebView2** (usually already installed).
- Allow **microphone** access when Mello Voice asks. If access wasn’t granted, use **Show permission prompt again** in the app, or turn on **Microphone access** and **Let desktop apps access your microphone** in Windows settings.
- This build is **not code-signed** yet — SmartScreen may say “Unknown publisher”. Choose **More info → Run anyway** if you trust this download.

### macOS

Use the **macOS disk image (.dmg)** link above, then drag **Mello Voice** to Applications.

- **macOS 11 or later**.
- Allow **microphone** access when prompted. If access wasn’t granted, use **Open microphone settings** in the app, enable Mello Voice under **Privacy & Security → Microphone**, then tap **Check again**. If paste does not work, grant **Accessibility** for Mello Voice in **System Settings → Privacy & Security**.

Installers include the Whisper runtime and English model — no extra download after install.
