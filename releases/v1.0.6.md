## What's new

**Mello Voice 1.0.6** fixes shortcut-key behaviour and lets you choose your own double-tap key.

- **Caps Lock works normally again** — a single press still toggles caps lock (or types a space, letter, or whatever key you picked). Dictation only starts when you **double-tap** the shortcut quickly, the same as before.
- **Choose your shortcut key** — open **Settings → Shortcut Key** and press any key you want to use for double-tap dictation. Reset to **Caps Lock** anytime with the reset button.
- **Shortcut hints follow your choice** — the empty-history hint and “Listening…” overlay copy show the key you picked, not a hard-coded label.

## Install

### Windows

Use the **Direct downloads** links above — **Windows setup (.exe)** is recommended; **MSI** is included for managed installs.

- **Windows 10 or 11 (64-bit)** and **Microsoft Edge WebView2** (usually already installed).
- Allow **microphone** access when Mello Voice asks. If access wasn’t granted, tap **Allow microphone access** in the app to try again.
- This build is **not code-signed** yet — SmartScreen may say “Unknown publisher”. Choose **More info → Run anyway** if you trust this download.

### macOS

Use the **macOS disk image (.dmg)** link above, then drag **Mello Voice** to Applications.

- **macOS 11 or later**.
- Allow **microphone** access when prompted. If access wasn’t granted, use **Open microphone settings** in the app, enable Mello Voice under **Privacy & Security → Microphone**, then tap **Check again**. If paste does not work, grant **Accessibility** for Mello Voice in **System Settings → Privacy & Security**.

Installers include the Whisper runtime and English model — no extra download after install.
