## What's new

**Mello Voice 1.0.9** fixes a first-run problem where local transcription could overwhelm your PC.

- **Safer first launch** — after you allow the microphone, Mello no longer hammers every CPU core while Whisper warms up. Transcription still runs locally on your machine; it just stays within sensible thread limits so Windows stays responsive.
- **Recommended if 1.0.8 felt stuck or frozen** on first open, especially on laptops or while other apps are running.

## Install

### Windows

Use the **Direct downloads** links above — **Windows setup (.exe)** is recommended; **MSI** is included for managed installs.

- **Windows 10 or 11 (64-bit)** and **Microsoft Edge WebView2** (usually already installed).
- Allow **microphone** access when Mello Voice asks. If access wasn’t granted, tap **Allow microphone access** in the app to try again.
- This build is **not code-signed** yet — SmartScreen may say “Unknown publisher”. Choose **More info → Run anyway** if you trust this download.

Installers include the Whisper runtime and English model — no extra download after install.
